# Garage Management System

A simple vehicle management system developed in Python using JSON for data storage.

## Features

- Register vehicles
- View registered vehicles
- Update vehicle information
- Delete vehicle records
- Automatic license plate generation
- License plate validation
- JSON data persistence

## Requirements

- Python 3.x

## How to Run

```bash
python main.py
```

## CRUD Operations

- Create: Register a new vehicle
- Read: View registered vehicles
- Update: Modify vehicle information
- Delete: Delete a vehicle record

## Technologies

- Python
- JSON
- Regular Expressions
- Secrets
